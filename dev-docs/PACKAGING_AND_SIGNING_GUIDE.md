# Packaging and Digital Signing Guide (CLI & Sideloading)

This document describes the workflow, issues, and solutions encountered when building, packaging, and digitally signing the Glance MSIX app package from the command line interface (CLI).

---

## 1. MSIX Packaging via CLI

To generate a packaged release version of Glance without Visual Studio, we use the .NET CLI. The command must specify outputting the MSIX package to a target directory:

```bash
dotnet publish -c Release -r win-x64 -p:GenerateAppxPackageOnBuild=true -p:AppxPackageDir="C:\Users\adria\GitHub\Glance\src\AppPackages\"
```

### Generated Outputs
The command creates a test package folder containing:
*   `Glance_1.0.0.0_x64.msix`: The main installer package.
*   `Add-AppDevPackage.ps1`: The Microsoft-provided developer sideload installer script.
*   `Install.ps1`: Silent installation script.
*   `Dependencies/`: Required runtime frameworks (Windows App SDK, VCLibs, etc.).

---

## 2. Certificate Verification Issue (Error 0x800B010A)

### The Problem
When building via CLI, the generated `.msix` package is unsigned by default (`Status: NotSigned`). Attempting to double-click the `.msix` file fails with the following Windows error:

> **This app package’s publisher certificate could not be verified.** Contact your system administrator or the app developer to obtain a new app package with verified certificates. The root certificate and all immediate certificates of the signature in the app package must be verified (0x800B010A).

Furthermore, the default certificate key file (`Glance_TestKey.pfx`) generated by Visual Studio is protected by an internal local password that MSBuild cannot access during CLI builds.

### The Solution

We resolve this by creating a fresh, password-controlled self-signed developer certificate matching the application's publisher details and signing the package manually:

1.  **Generate a new self-signed certificate** matching `CN=AppPublisher` (the publisher declared in `Package.appxmanifest`) with a known password (e.g., `glance`):
    ```powershell
    $cert = New-SelfSignedCertificate -Type Custom -Subject 'CN=AppPublisher' -KeyUsage DigitalSignature -FriendlyName 'Glance Test Cert' -CertStoreLocation 'Cert:\CurrentUser\My' -TextExtension @('2.5.29.37={text}1.3.6.1.5.5.7.3.3')
    $password = ConvertTo-SecureString 'glance' -AsPlainText -Force
    Export-PfxCertificate -Cert $cert -FilePath 'C:\Users\adria\GitHub\Glance\src\Glance_NewTestKey.pfx' -Password $password
    Export-Certificate -Cert $cert -FilePath 'C:\Users\adria\GitHub\Glance\src\AppPackages\Glance_1.0.0.0_x64_Test\Glance_1.0.0.0_x64.cer'
    ```

2.  **Sign the MSIX package manually** using the Windows SDK `signtool.exe` utility:
    ```powershell
    & 'C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe' sign /f 'C:\Users\adria\GitHub\Glance\src\Glance_NewTestKey.pfx' /p 'glance' /fd SHA256 'C:\Users\adria\GitHub\Glance\src\AppPackages\Glance_1.0.0.0_x64_Test\Glance_1.0.0.0_x64.msix'
    ```

## 3. Installation Steps for Sideloading

Before Windows trusts the signature, the public certificate (`Glance_1.0.0.0_x64.cer`) must be imported into the local machine's trust stores.

### Option A: Automated Script (Recommended)
1.  Navigate to the output folder: `C:\Users\adria\GitHub\Glance\src\AppPackages\Glance_1.0.0.0_x64_Test\`
2.  Right-click `Add-AppDevPackage.ps1` and select **"Run with PowerShell"**.
3.  Grant administrator permissions when prompted. The script automatically reads the `.cer` file and configures system trust before installing.

### Option B: Manual Trust via PowerShell (Admin)
If you prefer using the CLI or standard `.msix` double-click installer, run these commands in a **PowerShell (Administrator)** terminal:

```powershell
# 1. Register in Trusted Root Certification Authorities
Import-Certificate -FilePath "C:\Users\adria\GitHub\Glance\src\AppPackages\Glance_1.0.0.0_x64_Test\Glance_1.0.0.0_x64.cer" -CertStoreLocation Cert:\LocalMachine\Root

# 2. Register in Trusted People
Import-Certificate -FilePath "C:\Users\adria\GitHub\Glance\src\AppPackages\Glance_1.0.0.0_x64_Test\Glance_1.0.0.0_x64.cer" -CertStoreLocation Cert:\LocalMachine\TrustedPeople
```

Once imported, double-click `Glance_1.0.0.0_x64.msix` to install.
